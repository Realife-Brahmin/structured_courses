The implementation includes:
\begin{itemize}
    \item \texttt{hard\_threshold}: Operator that retains only the $s$ largest entries in absolute value
    \item \texttt{orthogonal\_matching\_pursuit}: Main OMP algorithm with normalized correlation-based column selection
    \item Normalized correlation computation: $\text{corr}_j = |\mathbf{a}_j^T \mathbf{r}| / (\|\mathbf{a}_j\|_2 \cdot \|\mathbf{r}\|_2)$
    \item Least squares solution on support set using pseudo-inverse: $\mathbf{x}_{\mathcal{S}} = A_{\mathcal{S}}^+ \mathbf{b}$
    \item Iterative testing for $s = 1, 2, \ldots, \text{rank}(A)$ to analyze recovery performance
\end{itemize}
