\textbf{Problem Statement:} Do Problem 23 c) from Section 3.4.

\textbf{Problem 3.4.23 c):} Find the order of convergence of the sequence:
$$x_n = \left(1 + \frac{1}{n}\right)^{\frac{1}{2}}$$

\vspace{1em}

\textbf{Solution:}

Let 
$$x_n = \left(1 + \frac{1}{n}\right)^{\frac{1}{2}}, \quad r := 1, \quad e_n := x_n - r.$$

Using the Taylor/binomial expansion $\sqrt{1 + t} = 1 + \frac{1}{2}t - \frac{1}{8}t^2 + O(t^3)$ as $t \to 0$ and taking $t = 1/n$, we get

$$e_n = \frac{1}{2n} - \frac{1}{8n^2} + O\left(\frac{1}{n^3}\right) \quad \text{so in particular} \quad e_n \sim \frac{1}{2n}.$$

Hence
$$e_{n+1} \sim \frac{1}{2(n+1)} = \frac{1}{2n}\left(1 - \frac{1}{n} + O(n^{-2})\right) = e_n\left(1 - 2e_n + O(e_n^2)\right),$$

i.e.
$$e_{n+1} = e_n - 2e_n^2 + O(e_n^3).$$

Now test the order $p$ via the limit $L_p = \lim_{n \to \infty} \frac{e_{n+1}}{e_n^p}$:

\begin{itemize}
\item For $p = 1$: $\frac{e_{n+1}}{e_n} \to 1$.

\item For any $p > 1$: since $e_n \sim \frac{1}{2n}$, we have 
$$\frac{e_{n+1}}{e_n^p} \sim \frac{1/(2n)}{(1/(2n))^p} = n^{p-1} \to \infty.$$
\end{itemize}

Thus no $p > 1$ gives a finite constant, while for $p = 1$ the constant is 1.

\begin{center}
\boxed{\text{Order } p = 1 \text{ with constant } C = 1 \text{ (sublinear convergence).}}
\end{center}

\textbf{Important Note:} While the order is $p = 1$, this is \textbf{NOT} linear convergence. Linear convergence requires both $p = 1$ \textbf{AND} $0 < C < 1$. Since $C = 1$ here, the convergence is \textbf{sublinear}. 

The distinction is crucial:
\begin{itemize}
\item \textbf{Linear convergence:} $p = 1$ and $0 < C < 1$ (errors decrease geometrically, relying on the $O(e_n)^2$ term difference to ensure technically $C < 1$)
\item \textbf{Sublinear convergence:} $p = 1$ and $C = 1$ (errors decrease slower than geometrically)
\item \textbf{Superlinear convergence:} $p = 1$ and $C = 0$, or $p > 1$
\end{itemize}

In this case, $e_n \sim \frac{1}{2n}$ shows the errors decrease like $1/n$, which is indeed sublinear. $\square$
