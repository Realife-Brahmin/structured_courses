\textbf{Problem Statement (Textbook 4.4.1):} 

Show that the norms $\|\mathbf{x}\|_\infty$, $\|\mathbf{x}\|_2$, and $\|\mathbf{x}\|_1$ satisfy the postulates (1), (2), and (3) for norms.

\vspace{0.5em}

\textbf{Norm Postulates~\cite{kincaid2009numerical, panchenko_448_notes}:}

On a vector space $V$, a \textbf{norm} is a function $\|\cdot\|$ from $V$ to the set of nonnegative reals that obeys these three postulates:

\begin{align*}
&\|x\| > 0 \text{ if } x \neq 0, \, x \in V \tag{1} \\
&\|\lambda x\| = |\lambda| \, \|x\| \text{ if } \lambda \in \mathbb{R}, \, x \in V \tag{2} \\
&\|x + y\| \leq \|x\| + \|y\| \text{ if } x, y \in V \quad \text{(triangle inequality)} \tag{3}
\end{align*}
