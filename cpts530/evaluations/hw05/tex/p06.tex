\textbf{Problem Statement (Textbook 4.4.33):} 

For any $n \times n$ matrix $A$, define

$$\|A\|_F = \left(\sum_{i=1}^{n} \sum_{j=1}^{n} a_{ij}^2\right)^{1/2}$$

(This is called the \textbf{Frobenius} norm.) Is this a subordinate matrix norm? Answer the same question for $\|A\| = \max_{1 \leq i,j \leq n} |a_{ij}|$. Prove that these equations define norms on the vector space of all $n \times n$ matrices.
