\subsection*{Singular Value Decomposition (SVD) and Pseudo-Inverse}

Given a matrix $M_{m \times n}$ with $\text{rank}(M) = r$, write
$$M = U\Sigma V^T$$
where $U_{m \times m}$ and $V_{n \times n}$ are orthogonal matrices, and $\Sigma_{m \times n}$ is a diagonal matrix with nonzero diagonal entries $\sigma_1 \geq \sigma_2 \geq \ldots \geq \sigma_r > 0$ called singular values of $M$.

\textbf{Definition.} Given $M$ as above, the pseudo-inverse $M^+$ is defined by
$$M^+ = V\Sigma^+ U^T$$
where $\Sigma^+_{n \times m}$ is the diagonal matrix whose non-zero entries are $\frac{1}{\sigma_1}, \frac{1}{\sigma_2}, \ldots, \frac{1}{\sigma_r}$.

\subsection*{Thresholding Operator}

The \textbf{hard thresholding operator} $H_s$ is defined as follows:
$$\mathbf{x} \to H_s(\mathbf{x}) \in \mathbb{R}^n$$

$H_s(\mathbf{x})$ sets all entries of $\mathbf{x}$ to zero except for $s$ largest (in absolute value) entries.

\subsection*{The Matrix $A_\mathcal{S}$}

Given a matrix $A$ and an index set $\mathcal{S}$, denote by $A_\mathcal{S}$ the matrix consisting of columns of $A$ with index in $\mathcal{S}$.

\subsubsection*{Key Observations}

\textbf{Feasibility vs. Recovery:}
\begin{itemize}
    \item \textbf{Matrix A:} At $s=1$, neither feasible nor recovers $\mathbf{e}_1$; at $s \geq 2$, both feasible and recovers $\mathbf{e}_1$
    \item \textbf{Matrix B:} At $s \geq 1$, both feasible and recovers $\mathbf{e}_1$
\end{itemize}

\textbf{Critical Insight:}

Success depends on the \emph{sparsity of the observation vector $\mathbf{b}$ in the column space} of the measurement matrix, NOT the sparsity of the original signal $\mathbf{x}$.

\begin{itemize}
    \item Matrix A needs $s=2$: $\mathbf{b}_A = (1,0,1)^T$ requires 2 columns for exact representation
    \item Matrix B needs $s=1$: $\mathbf{b}_B = (1,0)^T$ requires only 1 column for exact representation
\end{itemize}

\textbf{Compressed Sensing Advantage:}

Matrix B ($2 \times 3$, underdetermined) recovers the 1-sparse signal with fewer measurements than Matrix A ($3 \times 3$) because B is inherently better designed to capture 1-sparse signals. By removing redundant measurements (the third row of A), B efficiently represents sparse observations with minimal dimensions. This demonstrates the core principle of compressed sensing: with the \emph{right} measurement matrix, sparse signals can be recovered from fewer measurements than traditional methods require.

\textbf{Conclusion:} The experiment confirms that compressed sensing can achieve perfect sparse recovery with $m < n$ measurements when the measurement matrix is properly designed. Matrix B succeeds where Matrix A fails not because it has fewer measurements, but because its structure better aligns with the sparsity pattern of the observation vector.
