\textbf{Problem Statement:} Implement and analyze the Ridders' method for solving the equation $f(x) = 0$. For guidance, you might wish to read the Wikipedia page on the Ridders' method. Also feel free to consult other sources.

\subsection*{Brief Description of the method}

Given the initial bracketing interval $[x_0, x_2]$, containing \textbf{one} solution, and such that $f(x_0)$ and $f(x_2)$ have opposite signs, compute the midpoint $x_1 = (x_0 + x_2)/2$. Then define a new function $h(x) = f(x)e^{ax}$. Find the parameter $a$ that ensures $h(x_1) = \frac{1}{2}(h(x_0) + h(x_2))$. Then define $x_3$ as the $x$-intercept of the line passing through $(x_0, h(x_0))$ and $(x_2, h(x_2))$. Use $x_3$ as one of the endpoints of the next interval bracketing the solution. The other endpoint is $x_1$ if $f(x_1)f(x_3) < 0$. Otherwise, choose either $x_0$ or $x_2$ based on the requirement that the sign of $f(x)$ at the chosen point must be opposite to the sign of $f(x_3)$. Continue until the desired accuracy is reached.

\addcontentsline{toc}{subsection}{Problem 5.4}

\textbf{Solution:}

\subsubsection*{Need for a Wider Interval}

While the interval $[\text{-}0.8,\,\text{-}0.6]$ was suitable for root finding (as shown in Part 3), it is \textbf{too small for proper convergence analysis}. Ridders' method converges so rapidly on this small interval that it reaches the solution in just 1 iteration, making it impossible to observe the convergence behavior over multiple iterations.

To properly analyze and compare the convergence rates of both algorithms, I extended the analysis to a much wider interval $[\text{-}100,\,100]$ with tighter tolerances $\epsilon = 10^{-12}$ and $\delta = 10^{-12}$. This wider interval:
\begin{itemize}
    \item Forces both methods to perform many more iterations before converging
    \item Allows us to observe the characteristic convergence patterns of each method
    \item Provides sufficient data points to compute meaningful convergence order estimates
    \item Demonstrates the robustness of both methods when starting far from the root
\end{itemize}

The Mean Value Theorem condition is satisfied since $f(\text{-}100) = \text{-}10000 < 0$ and $f(100) = 2.688 \times 10^{43} > 0$, confirming that $f(\text{-}100) \cdot f(100) < 0$.

\subsubsection*{Convergence Order Analysis}

To quantify the convergence rate, I computed the approximate convergence order using the formula:
$$p \approx \frac{\log(|e_{n+1}|/|e_n|)}{\log(|e_n|/|e_{n-1}|)}$$
where $e_n = |x_n - x^*|$ is the absolute error at iteration $n$, and $x^*$ is the true root.

\paragraph{Ridders' Method Convergence Order}

The \textbf{convergence order analysis table} for Ridders' method demonstrates superlinear convergence, as shown in the terminal output from \Cref{fig:ridders-output}.

Key observations:
\begin{itemize}
    \item The estimated convergence order is $p \approx 1.717$ (averaged over iterations 4--11)
    \item This is close to the theoretical order of $p = 1.839$ for Ridders' method
    \item The order $p > 1.7$ confirms \textbf{superlinear convergence}
    \item Early iterations show $p \approx 2.1$--2.2, while later iterations show $p \approx 1.2$--1.4 due to machine precision limits
\end{itemize}

\paragraph{Bisection Method Convergence Order}

The \textbf{convergence order analysis table} for the bisection method demonstrates linear convergence, as shown in the terminal output from \Cref{fig:bisection-output-extended}.

Key observations:
\begin{itemize}
    \item The estimated convergence order is $p \approx 1.104$ (averaged over iterations 4--15)
    \item This is very close to the theoretical order of $p = 1.0$ for bisection
    \item The order $p \approx 1.0$ confirms \textbf{linear convergence}
    \item \textbf{Important note:} The convergence order for bisection is typically not computed using the error ratio formula shown above. Instead, it is commonly expressed as the interval reduction factor: the error decreases by a factor of $\frac{1}{2}$ at each iteration, giving $|e_{n+1}| = \frac{1}{2}|e_n|$ or order $\mathcal{O}(n) = (1/2)^n$. However, for consistency with the Ridders' analysis and to provide a direct comparison, we computed the average convergence order using the same formula, which yields $p \approx 1.104$.
\end{itemize}

\subsubsection*{Discussion and Conclusions}

The numerical comparison reveals several important insights:

\begin{enumerate}
    \item \textbf{Efficiency:} Ridders' method is significantly more efficient, requiring only 12 iterations compared to 47 for bisection (a 4$\times$ reduction) to achieve the same tolerance of $10^{-12}$.
    
    \item \textbf{Convergence Rate:} The convergence order analysis confirms theoretical predictions:
    \begin{itemize}
        \item Ridders' method: $p \approx 1.717$ (superlinear, theoretical $\approx 1.839$)
        \item Bisection method: $p \approx 1.104$ (linear, theoretical $= 1.0$)
    \end{itemize}
    
    \item \textbf{Robustness:} Both methods successfully converged from the very wide initial interval $[\text{-}100,\,100]$, demonstrating their robustness. However, Ridders' method maintained its superior convergence rate even when starting far from the root.
    
    \item \textbf{Practical Implications:} For problems requiring high accuracy, Ridders' method offers a compelling advantage over bisection. The superlinear convergence means that as iterations progress, each new iteration provides exponentially more accuracy than the previous one, whereas bisection improves by a constant factor of 2 per iteration.
\end{enumerate}

In summary, Ridders' method achieves an approximate convergence order of $p \approx 1.717$, demonstrating superlinear convergence that is substantially faster than the linear convergence of bisection ($p \approx 1.0$). This makes Ridders' method the preferred choice when computational efficiency is important and function evaluations are not prohibitively expensive.
