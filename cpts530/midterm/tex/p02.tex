\textbf{Problem Statement:} Consider the following variation of the Newton's method:
$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_0)}.$$

Find constants $C$ and $s$ such that
$$e_{n+1} = Ce_n^s.$$

\noindent\rule{\textwidth}{0.4pt}

\vspace{1em}

\textbf{Solution:}

We start with the given iteration formula:
\begin{equation*}
    x_{n+1} = x_n - \frac{f(x_n)}{f'(x_0)}
\end{equation*}
Let the true root be $r$, and define the error at step $n$ as $e_n = x_n - r$. Then,
\begin{align*}
    e_{n+1} &= x_{n+1} - r \\
    &= x_n - \frac{f(x_n)}{f'(x_0)} - r \\
    &= (x_n - r) - \frac{f(x_n)}{f'(x_0)} \\
    &= e_n - \frac{f(x_n)}{f'(x_0)}
\end{align*}
Next, we use the Taylor expansion of $f(x_n)$ around the root $r$:
\begin{equation*}
    f(x_n) = f(r) + f'(r)(x_n - r) + \frac{f''(r)}{2}(x_n - r)^2 + O((x_n - r)^3)
\end{equation*}

Substituting this expansion into our expression for $e_{n+1}$ gives:
\begin{align*}
    e_{n+1} &= e_n - \frac{f(r) + f'(r)e_n + \frac{f''(r)}{2}e_n^2 + O(e_n^3)}{f'(x_0)} \\
    &= e_n - \frac{f(r)}{f'(x_0)} - \frac{f'(r)e_n}{f'(x_0)} - \frac{f''(r)}{2f'(x_0)}e_n^2 - \frac{O(e_n^3)}{f'(x_0)}
\end{align*}
Rearranging terms, we have:
\begin{align*}
    e_{n+1} &= \left(1 - \frac{f'(r)}{f'(x_0)}\right)e_n - \frac{f''(r)}{2f'(x_0)}e_n^2 + O(e_n^3)
\end{align*}
To determine the order of convergence, we analyze the leading term in the expression for $e_{n+1}$. Assuming that $f'(r) \neq f'(x_0)$, the term $\left(1 - \frac{f'(r)}{f'(x_0)}\right)e_n$ dominates as $e_n \to 0$. Thus, we identify:
\begin{equation*}
    C = \left|1 - \frac{f'(r)}{f'(x_0)}\right|, \quad s = 1
\end{equation*}
Therefore, the error satisfies:
\begin{equation*}
    e_{n+1} = C e_n^s
\end{equation*}
with $C = \left|1 - \frac{f'(r)}{f'(x_0)}\right|$ and $s = 1$.
It may be noted that if $f'(r) = f'(x_0)$, the leading term vanishes, and the convergence order would then be determined by the next term(s), depending on the first non-vanishing derivative of $f$ at the root $r$, so if $f''(r) \neq 0$, we would have quadratic convergence ($s = 2$), and if $f''(r) = 0$ but $f'''(r) \neq 0$, we would have cubic convergence ($s = 3$), and so on.

If $f'(r) \neq f'(x_0)$, we don't really have any idea whether the method converges or not; while the error ratios are linear, we cannot guarantee $0 < C < 1$; if $C \geq 1$, the method may very well diverge. In fact if $f'(x_0)$ and $f'(r)$ have opposite signs, then surely $C > 1$ and the method diverges.


% Add reference before the tcolorbox
The following \textbf{box} summarizes the error order parameters and remarks on convergence for this fixed-point iteration method:

\begin{tcolorbox}[colback=gray!10!white, colframe=black!80!white, title=Convergence Summary]
\textbf{Case-by-case conclusion:}

\begin{itemize}
    \item If $f'(x_0) \neq f'(r)$:
    \[
        s = 1, \qquad C = \left|1 - \frac{f'(r)}{f'(x_0)}\right|, \qquad \text{Convergence not guaranteed}
    \]
    \item If $f'(x_0) = f'(r)$ and $f^{(k)}(r) = 0$ for $2 \leq k < n$, but $f^{(n)}(r) \neq 0$:
    \[
        s = n, \qquad C = \left|\frac{f^{(n)}(r)}{n!\,f'(x_0)}\right|, \qquad \text{Converges with order } n
    \]
    (where $n$ is the smallest integer $\geq 2$ such that $f^{(n)}(r) \neq 0$)
\end{itemize}

\end{tcolorbox}

\textbf{Aside}: In Power System Analysis, we use Fast Decoupled Newton Raphson method which approximates the Jacobian at each iteration with the Jacobian at the initial guess, similar to this method. This can lead to slower convergence or divergence if the initial guess is not close enough to the true solution, but it significantly reduces computational effort per iteration.
