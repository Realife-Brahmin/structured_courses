Applying KVL on the the circuit in Fig 1.:
\begin{align}
    && V_{\rm dc} \;=\; r_L\,i_L \;+\; L\,\dot i_L \;+\; v_C \label{eq:kvl}
    &\Rightarrow && \boxed{\;\dot i_L \;=\; \frac{1}{L}\,\big(-\,r_L i_L \;-\; v_C \;+\; V_{\rm dc}\big)\;}\tag{1}
\end{align}

The capacitor current-voltage relation is:
\begin{align}
    && i_L \;=\; C\,\dot v_C 
    \quad\Rightarrow\quad 
    \boxed{\;\dot v_C \;=\; \frac{1}{C}\,i_L\;}\tag{2} \label{eq:vc}
\end{align}

Eliminate $v_C$ in \eqref{eq:kvl} by differentiating wrt time and using \eqref{eq:vc} to get a 2nd-order ODE in $i_L$:

\[
\ddot i_L \;=\; \frac{1}{L}\big(-r_L \dot i_L - \dot v_C\big)
\;=\; -\frac{r_L}{L}\,\dot i_L \;-\; \frac{1}{LC}\,i_L
\]
\[
\boxed{\;\ddot i_L \;+\; \frac{r_L}{L}\,\dot i_L \;+\; \frac{1}{LC}\,i_L \;=\; 0\;} \label{eq:2nd_order_ODE}
\]

\noindent\text{Characteristic polynomial and comparison with the canonical 2nd-order form:}
\[
s^2 + \frac{r_L}{L}s + \frac{1}{LC}=0
\qquad\Longleftrightarrow\qquad
s^2 + 2\zeta\omega_n s + \omega_n^2=0
\]
\[
\boxed{\;\omega_n=\frac{1}{\sqrt{LC}},\qquad
\zeta=\frac{r_L}{2*\sqrt{\frac{L}{C}}}}
\]
